# KARMO Full Predeploy Review Pack

Use this directory for morning review of the isolated staging branch.

- `KARMO_PREDEPLOY_STATUS.md` — current staged progress and explicit incompleteness.
- `KARMO_CLAUDE_REVIEW_PROMPT.md` — independent adversarial code/security review instructions.
- `KARMO_REVIEW_PROMPT.md` — KARMO System-Fit/invariant review instructions.
- `KARMO_PREDEPLOY_REVIEW_CHECKLIST.md` — mechanical review gates.
- `KARMO_PREDEPLOY_DEPLOYMENT_TEMPLATE.md` — separate post-approval deployment/rollback template; not executable authorization.
- `KARMO_NEXT_AGENT_FRENZY.md` — context-window-safe next-agent handoff preserving KARMO authority.

No file in this review pack authorizes a merge or production change.
