# KARMO Learning Labs

Hands-on code for Natalie's AI/agent engineering training lives here.

## Rules
- Use synthetic or explicitly approved sample data.
- Do not connect lab code to KARMO production.
- Keep local virtual environments, caches, model files, secrets, databases, and generated outputs out of Git.
- Natalie writes/modifies the code that is central to each lesson.
- Claude may scaffold supporting files when approved.
- Each lab should include at least one deliberate failure/adversarial case and a short explanation of what was learned.

## Layout
Each lesson gets its own directory when code is first created, for example:

```text
learning-labs/day01/
learning-labs/day02/
```

Do not pre-populate complete solutions before Natalie performs the exercise.
