# KARMO Learning Workspace

This directory contains Natalie's interactive AI/agent engineering program.

## Purpose
The goal is hands-on engineering skill: use real tools, write code, create failures, debug them, and connect the result back to KARMO architecture.

## Canonical learning files
- `KARMO_AI_AGENT_ENGINEERING_LEARNING_PLAN.md` — master curriculum.
- `SETUP_AND_TOOLCHAIN.md` — approved local learning environment and tool setup guidance.
- `PROGRESS_TRACKER.md` — completed lessons, labs, evidence, and next lesson.
- `DAY_01_LLM_PYTHON_CONTROL.md` — first hands-on lesson.

## Boundary
Learning work stays isolated from KARMO production. No educational lab may access or modify production KARMO systems unless Natalie separately authorizes that specific production action under KARMO governance.

## Working model
ChatGPT teaches/reviews and challenges reasoning. Claude Code may prepare scaffolding or perform larger setup work. Natalie writes and modifies the code that is central to the lesson and explains the outcome in her own words.
